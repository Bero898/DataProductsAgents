# Data Product

This directory contains modified examples from different data product specifications and implementations. The following sources have been used and modified based on ProMoTe.owl provided by [ProMoTe]{https://github.com/Stefan-Driessen/ProMoTe/blob/main/ProMoTe.owl}:

## ChatGPT_DMesh
Synthetic data mesh created using ChatGPT. The conversation can be found in the following [link]{https://chatgpt.com/share/6831df22-5a70-800e-8105-a2b4862730dc}

## Data Contract Playground - Pflooky
Original files from [data-contract-playground]{https://github.com/data-catering/data-contract-playground/tree/main} have been modified to include ProMoTe specifications:
- `data-contract-specification_ProMoTe.yaml`
- `dataproduct_ProMoTe.yaml`

## Data Mesh Manager - Simon Harrer
Original files from [datamesh-manager]{https://github.com/datamesh-manager/example-gitops-repository/tree/main/dataproducts} have been modified to include ProMoTe specifications:
- `glue_catalog_database_shelf_warmers_v1_ProMoTe.yaml`
- `s3_bucket_shelf_warmers_v1_ProMoTe.yaml`

## Data Product Examples - Agile Labs
Original files from [data-product-specification]{https://github.com/agile-lab-dev/Data-Product-Specification} have been modified to include ProMoTe specifications:
- `example-ProMoTe.yaml`

## Additional Files
- `ProMoTe.owl`: The ontology file for ProMoTe specifications

Note: Files ending with `_ProMoTe.yaml` are modified versions of their original counterparts to demonstrate ProMoTe integration.
